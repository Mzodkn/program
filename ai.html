العلامة 01 OVERLAP & CONVERGENCE

🧩 التكرار والتقاطع البرمجي

القاعدة: تُبنى الخيارات الخاطئة من أجزاء الإجابة الصحيحة. الخيار الذي يجمع "الشق الأول الأكثر تكراراً" مع "الشق الثاني الأكثر تكراراً" هو الإجابة الصحيحة.

مثال 1 (برمجة C++ - المصفوفات):
Q: Which declaration correctly creates an array of 5 integers in C++?
A. int arr(5);
B. int arr[5]; ✔
C. array int arr[5];
D. int[5] arr;

💡 التحليل: البداية int arr تكررت 3 مرات، والنهاية [5]; تكررت مرتين؛ تقاطعهما يعطي (B) فوراً!

مثال 2 (برمجة C++ - عناصر المصفوفة):
Q: Which statement assigns the value 25 to the third element of array A?
A. A[3] = 25;
B. A[2] = 25; ✔
C. A(2) = 25;
D. A[1] = 25;

💡 التحليل: الأقواس المربعة A[...] تكررت 3 مرات، والرقم 2 تكرر مرتين؛ نقطة التقاطع هي (B)!

العلامة 02 CROSS-QUESTION LEAKAGE

🕵️‍♂️ التسريب بين الأسئلة

القاعدة: من أقوى العلامات في امتحانات البرمجة؛ حيث يكتب الأستاذ كوداً كاملاً في "سؤال تتبع المخرجات" يكشف لك إجابات أسئلة القواعد (Syntax) السابقة!

مثال 1 (تسريب المؤشرات Pointers في نفس الصفحة):
Q8: Which operator is used to get the address of a variable? (A. * | B. & | C. # | D. %)
Q10: What is the correct declaration of a pointer to an integer? (A. int p; | C. int *p;)
Q11 (الكود المسرِّب للإجابة!):
int x = 10; int *p = &x; cout << *p;

💡 التحليل: السطر int *p = &x; في السؤال 11 أعطاك إجابة السؤال 10 (int *p;) وإجابة السؤال 8 (&) مجاناً!

مثال 2 (تسريب تعريف واستدعاء الدوال Functions):
Q18: Which statement correctly calls a function named display that takes no arguments? (A. call display; | B. display();)
Q17 (الكود المسرِّب للإجابة!):
int square(int x) { return x * x; }
cout << square(4);

💡 التحليل: السؤال 17 استدعى الدالة بكتابة اسمها مع قوسين square(4) بدون كلمة call أو function، مما يحل السؤال 18 (display();)!

العلامة 03 LONGEST & DETAILED OPTION

📏 الإجابة الأطول والأكثر تفصيلاً

القاعدة: يضطر الكاتب أو الذكاء الاصطناعي لإضافة تفاصيل وشروط توضيحية في الخيار الصحيح ليكون كاملاً وصحيحاً علمياً، بينما تخرج المشتتات الخاطئة قصيرة.

مثال 1 (برمجة C++ - سؤال 14):
Q: Which keyword is used to define a function in C++?
A. function (1 word)
B. define (1 word)
C. void (1 word)
D. C++ does not use a keyword; the return type is written before the function name ✔ (14 words!)

💡 التحليل: فرق الطول الصارخ (14 كلمة مقابل كلمة واحدة فقط في A, B, C) يكشف الإجابة الصحيحة من النظرة الأولى!

مثال 2 (مقدمة IT - سؤال 2):
Q: What is the primary purpose of a feedback mechanism in an IS?
A. To store data for future use.
B. To convert data into useful outputs.
D. To use information from the system to make changes to input or processing activities. ✔

💡 التحليل: الخيار (D) يبلغ ضعف طول بقية الخيارات لاحتوائه على التعريف الكامل من المحاضرة.

العلامة 04 ABSOLUTE TERMS TRAP

🚫 فخ الكلمات المطلقة (Only / Always / All)

القاعدة: يلجأ الذكاء الاصطناعي لصناعة خيارات خاطئة عن طريق وضع كلمات تعميم قاطعة مثل (only, always, all, never). استبعدها فوراً!

مثال 1 (برمجة C++ - سؤال 7):
Q: What does a pointer store?
A. A character only ✘
B. The address of another variable ✔
C. A function name only ✘

💡 التحليل: الكلمة القاطعة only فضحت الخيارين الخاطئين (A و C)، وتركت (B) كإجابة صحيحة.

مثال 2 (برمجة C++ - سؤال 19):
Q: What is the main advantage of using functions?
A. They make code reusable and organized ✔
B. They always make programs shorter ✘
D. They prevent all errors ✘

💡 التحليل: في البرمجة لا توجد أداة تمنع "كل" الأخطاء (all) أو تقصّر الكود "دائماً" (always).

العلامة 05 OPPOSITE PAIRS

⚖️ الزوج المتضاد (الثنائيات المتقابلة)

القاعدة: عند وجود مصطلحين متعاكسين تماماً أو متقابلين في الخيارات، فالإجابة الصحيحة غالباً ما تكون أحدهما، وباقي الخيارات حشو لإكمال العدد.

مثال (برمجة C++ - سؤال 20 + المنطق الرياضي سؤال 7):
Q20: Which function call type used if the function parameter is pointer?
A. Call by value. (قطب 1)
B. Call by reference. ✔ (قطب 2)
C. Both are true.
D. Both are false.

💡 التحليل: التضاد المباشر بين Call by value و Call by reference يلغي الخيارين (C و D) فوراً ويحصر تركيزك في الخيارين الأولين.
